## Slug convention

The merge script (to be built) will derive a stable slug from each play-aid H2 by:
1. Take the H2 text.
2. Strip everything after the first ` — ` (em-dash) or ` - ` (hyphen-with-spaces) separator.
3. Strip everything after the first ` (` parenthesis.
4. Strip trailing `:` and `.`.
5. Lowercase, replace whitespace and punctuation with `-`.
6. Trim leading/trailing `-`.

Examples:
- `## OPS Track Events — Trigger after both players move to/past` → `pa2:ops-track-events`
- `## Use At Any Time (not an action)` → `pa2:use-at-any-time`
- `## Detection of TFs (by MP, RORSAT, Tattletale)` → `pa4:detection-of-tfs`
- `## Missile Attacks on TFs vs. Task Forces` → `pa4:missile-attacks-on-tfs`
- `## Facility Damage - Effects cumulative` → `pa6:facility-damage`

The merge script should reject slug collisions (duplicate H2s producing the same slug) and emit a clear error pointing at line numbers — that's how PA-6's duplicate SAM H2s will be caught and forced to disambiguate.
