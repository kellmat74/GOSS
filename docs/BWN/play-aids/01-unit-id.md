# Play Aid 1 — How to Read Air & Naval Units

> Source: Compass Games BWN Play Aids PDF, page 1. Transcribed verbatim from the counter-anatomy reference card.
> Each section here is a discrete reference unit suitable for surfacing in workflow tools (e.g. "What does this counter mean?" lookup).

## How to Read Air Units

Air-unit counters annotate the following data, by position around the unit silhouette:

- **Country** (top-left of counter)
- **Unit Type** (FTR / STK / MP / TKR)
- **Defense** (bottom-left)
- **Air Range** (top-right)
- **No. of Missiles** (right edge)
- **Tactical Value** (varies by type)
- **TF Detection** (MP units)
- **Anti-Submarine** value (MP units)
- **SEAD Bonus** (some STK)
- **Carrier ID Bar** (carrier-borne units — color band)
- **Unit Name** (bottom strip)
- **Extended Air Range** (some STK)
- **+2 Range / +1 Range / +2 Tactical Value** modifiers (tankers and certain support types)

### Air Unit Types (key)

| Code | Type           | Notes |
|------|----------------|-------|
| FTR  | Fighter        | Always on CAP when fresh; air-to-air primary |
| STK  | Strike         | Bombing / ASM / Cruise missile delivery |
| MP   | Maritime Patrol | Detect TFs and submarines; some ASW capable |
| TKR  | Tanker         | Extends range of escorted strikes |

### Other Items on Air Counters

- ★ Denotes an Optional Rule
- Unit begins in Reserve marker

## How to Read Naval Units

Naval-unit counters annotate:

- **Country** (top-left)
- **Tactical Value** (some classes)
- **Defense** (left side)
- **Anti-Submarine** value
- **Anti-Surface** value
- **6+ Save** (capital ships)
- **8+ Save** (super-capital ships)
- **Small / Diesel** indicator for submarines
- **Ship has air units icon** (CV / CVH / carrier-capable)
- **Land Attack Cruise Missiles** count
- **SAMs** count
- **Prairie Masker** (signature reduction)
- **Carrier Bar** (color)
- **Rocket Torpedo** (RBU)
- **SSBN Payload** (ballistic-missile boats)
- **Long Range / Short Range Anti-Ship Missiles** count
- **Anti-Ship (Sunburn) Missiles** count
- **Anti-Ship (Shipwreck) Missiles** count
- **Big Target** (carriers, large amphibs)
- **Limited Ammunition** marker
- **Unit Name** (bottom strip)
